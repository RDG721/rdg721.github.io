## 📝 Overview

NPMCommander helps you run NPM build and install commands without needing to use the terminal. Designed for MacOS users, this app simplifies common tasks in software development. Whether you're working on a project or installing packages, NPMCommander makes the process straightforward.

## ⚙️ Features

- **User-Friendly Interface:** No terminal knowledge is required.
- **Quick Access:** Easily run NPM build and install commands.
- **MacOS Compatibility:** Optimized for a seamless experience on Mac systems.
- **Efficiency Boost:** Save time by reducing errors in command inputs.

## 🖥️ System Requirements

- MacOS 10.14 (Mojave) or later
- At least 4 GB of RAM
- Node.js installed on your system (at least v12.x)

## 🔧 Troubleshooting

If you encounter any issues while using NPMCommander, consider the following:

- **Application Won't Open:**  
   Ensure that you have the right version of MacOS and that Node.js is installed.

- **Commands Not Running:**  
   Check if you have selected the correct project folder. Ensure the project has a valid `package.json` file.
